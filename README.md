# Навыки для резюме по профессиям: открытый список (JSON, CSV) и сверка резюме с вакансией

Открытые данные на русском языке и небольшой скрипт на Python без зависимостей:

- **ключевые навыки для резюме по 94 профессиям** (повар, бухгалтер, менеджер по продажам, программист, медсестра, электрик, юрист и другие): 1 616 навыков в `data/skills_by_profession.json` и `data/skills_by_profession.csv`;
- **сверка резюме с текстом вакансии** по ключевым словам: показывает, какие слова вакансии есть в резюме и каких не хватает;
- **проверка резюме по типовым навыкам профессии**: что из обычного набора навыков вы уже написали, а что можно добавить.

Подходит для самопроверки резюме, чат-ботов и HR-сервисов, обучающих проектов и экспериментов с языковыми моделями.

> Скрипт ищет совпадения слов и не оценивает качество резюме. Добавляйте в резюме только те навыки, которыми вы действительно владеете.

## Быстрый старт

```bash
git clone https://github.com/kizhaev77-sudo/resume-skills-ru.git
cd resume-skills-ru
python resume_check.py list                         # все профессии и их коды
python resume_check.py skills povara resume.txt     # типовые навыки профессии
python resume_check.py resume.txt vacancy.txt       # сверка резюме с вакансией
```

Пример сверки с вакансией:

```
Охват ключевых слов вакансии: 78%
Есть в резюме: мене, прод, холо, звон, amoc, веде, пере
Нет в резюме: треб, exce
```

## Как составить список навыков для резюме

В датасете навыки уже разложены так, как их удобно вставлять в раздел «Ключевые навыки»: программы и системы (1С, iiko, Битрикс24, Excel), профессиональные приёмы и документы. Полное объяснение, как описывать навыки и подтверждать их примерами, есть на странице [«Навыки для резюме»](https://rezumebox.ru/navyki-dlya-rezyume.html).

Пример записи:

```json
{
  "slug": "povara",
  "profession_genitive": "повара",
  "skills": ["Горячий цех", "Холодный цех", "Технологические карты", "ХАССП", "iiko"],
  "url": "https://rezumebox.ru/rezyume-povara.html"
}
```

В поле `url` ссылка на страницу с примером резюме этой профессии: образец, обязанности, что написать о себе, вопросы на собеседовании.

## Сверка резюме с вакансией

Скрипт берёт самые частые значимые слова из текста вакансии, приводит слова к грубой основе (цех, цеха, цехом считаются одним словом) и проверяет, есть ли они в резюме. Это быстрый способ заметить, что вакансия просит Excel, а в резюме его нет. Для тонкой проверки есть [проверка резюме под вакансию онлайн](https://rezumebox.ru/proverit-rezyume.html) и [проверка резюме на ATS](https://rezumebox.ru/proverka-rezyume-ats.html).

Если нужен не список слов, а разбор резюме под конкретную вакансию, на [rezumebox.ru](https://rezumebox.ru/) можно загрузить резюме и вакансию и получить отчёт: что переписать, что добавить, какие вакансии подходят. Для самостоятельного использования данных сайт не нужен.
